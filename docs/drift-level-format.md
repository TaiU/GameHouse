# 迴廊幻境：關卡格式

關卡放在 `js/drift-levels.js`，設定 `window.DriftLevels = [ ... ]`，一章一個物件。引擎在 `js/drift.js`，規則以引擎為準。

## 座標與畫面

- 每個方塊是一個單位立方體，座標是整數 `[x, y, z]`（方塊中心）。z 往上；畫面上 x 往右下、y 往左下。
- 鏡頭固定在等角視角。頂面的「畫面格」是 `K = (x−z, y−z)`，深度是 `x+y+z`（越大越靠前）。
- `(x,y,z)` 和 `(x+1,y+1,z+1)` 的頂面在畫面上完全重疊，這就是「不可能的連接」的來源。

## 規則（看起來接上就走得過去）

1. 一個頂面可以走，要同時滿足：方塊沒有標成 `'n'`；畫面格 `K`、`K−(1,0)`、`K−(0,1)`、`K−(1,1)` 裡沒有任何深度更大的方塊（也就是整個頂面沒被任何更靠前的方塊遮到一點點）。
2. 兩個可走頂面的畫面格上下左右相鄰（差 1），就連通。走路不算操作。
3. 操作（每次都可以往兩個方向）：
   - **轉動建築**：整座建築繞垂直軸轉 90°，`(dx,dy) → (−dy,dx)` 是向右轉。旅人跟著建築一起轉。
   - **滑塊** `slide`：在 `states` 的位移之間往前或往回一格。預設到頭就停，`loop: true` 則循環。
   - **轉台** `turn`：繞 `pivot` 那一格的垂直軸轉 90°，四個狀態循環。
   - 站在機關方塊上時，旅人會跟著機關移動。
4. 操作會被拒絕的情況：有方塊會落在旅人頭上那一格；兩個方塊會重疊；有 `lever` 但旅人沒站在拉桿方塊上；`turn` 的 `axis` 是 `'x'`/`'y'` 而旅人站在它上面；滑塊已經到頭。
5. 走到 `goal` 那個方塊的頂面就過關。

## 欄位

```js
window.DriftLevels = [{
  id: 'ch1',                 // 唯一代號
  name: '晨光步道',           // 章名（建議 2–6 字）
  hint: '一句提示，顯示在畫面下方',
  par: 2,                    // 最少操作次數（轉建築＋撥機關），引擎會核對
  blocks: [[0,0,0], [1,0,0], [3,1,0,'n']],  // 靜態方塊；第 4 欄 'n' = 裝飾，永遠不能走
  start: [0,0,0],            // 起點方塊的座標（初始位置）
  goal: [1,0,0],             // 終點方塊的座標（可以是機關方塊的初始位置）
  views: true,               // 可省略，預設 true；false = 這章不能轉動建築
  center: [2, 1.5],          // 可省略，只影響取景（轉動中心），不影響規則；整數或 .5
  pieces: [                  // 可省略
    { label: '石橋', kind: 'slide', blocks: [[2,3,0]], states: [[0,0,0],[0,-1,0],[0,-2,0]], loop: false, lever: [0,0,0] },
    { label: '轉台', kind: 'turn', blocks: [[4,0,0],[5,0,0],[6,0,0]], pivot: [5,0] },
    { label: '吊橋', kind: 'turn', axis: 'x', pivot: [0,3,0], blocks: [[0,3,-1],[0,3,0],[0,3,1]] },
  ],
  theme: 0,                  // 可省略：0–5 的色票編號，或 { sky:[上,下], sun, path:[頂,左,右], stone:[...], mech:[...], hero }
  mood: 0,                   // 可省略：給音樂的氣氛編號，預設是章節編號
}];
if (typeof module !== 'undefined') module.exports = window.DriftLevels;  // 可有可無
```

- `pieces[].blocks` 寫的是位移 `[0,0,0]`／狀態 0 時的位置；一開始在 `states[0]`（通常是 `[0,0,0]`）。
- `lever` 必須是某個靜態方塊的座標。畫面上那塊會畫成圓形踏板，機關的鈕只有旅人站在上面時才會亮。
- 方塊在任何狀態下都不要重疊（引擎會拒絕造成重疊的操作，但最好設計上就避開）。

## 檢查與截圖

```sh
node tools/drift-check.js js/drift-levels.js   # 錯誤、警告、最少操作次數 vs par、一組解法、畫面格地圖
node tools/drift-shot.js drift-shots 640       # 用真正的遊戲畫面，逐章截「開始」和「照解法操作完」兩張
```

開發時用 `index.html?drift-dev#drift` 會解鎖所有章節，`?drift-dev&drift-level=3#drift` 直接開第 4 章。
